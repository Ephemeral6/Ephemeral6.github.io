# 首页背景图片说明

## 如何添加背景图片

### 步骤1：准备图片

将你的背景图片重命名为以下名称之一：
- `hero-bg.jpg`（推荐，如果是JPG格式）
- `hero-bg.png`（如果是PNG格式）

### 步骤2：放置图片

将图片复制到这个文件夹：
```
/home/user/Ephemeral6.github.io/docs/assets/images/
```

### 步骤3：刷新网页

完成！刷新浏览器即可看到背景图片。

## 图片建议

- **尺寸**：1920x1080 或更高
- **大小**：< 500KB（压缩后）
- **格式**：JPG（推荐）或 PNG
- **风格**：深色调图片效果更好

## 当前状态

- ✅ 已配置渐变色备用背景（深蓝到紫色）
- ⏳ 等待添加图片：`hero-bg.jpg` 或 `hero-bg.png`

## 效果

添加图片后：
- 图片会自动覆盖渐变色背景
- 自动添加深色遮罩确保文字清晰
- 桌面端支持视差滚动效果
- 移动端自动优化显示
